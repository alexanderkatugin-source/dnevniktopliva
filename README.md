Описание: 
Всегда знайте, сколько топлива у вас в баке!

«Дневник: Остаток в баке» — это простой и надежный инструмент для учета ГСМ и пробега. Он создан специально для водителей, которые должны четко отслеживать свои расходы и предоставлять отчетность.

Кому подходит приложение:
• Водителям служебных автомобилей, заправляющимся по корпоративным топливным картам.
• Водителям личных авто, которые используют топливную карту предприятия.
• Тем, кому компания возмещает стоимость топлива по чекам (и нужно подтвердить расходы).
• Логистам, курьерам и всем, кто ценит порядок в учете транспорта.

Больше не нужно держать в голове цифры или носить с собой блокнот. Внесите данные один раз, и приложение автоматически посчитает все за вас.

Главные возможности:
🛢️ Наглядный остаток: Большой индикатор показывает текущее топливо в баке. Он меняет цвет (зеленый, желтый, красный), предупреждая о низком уровне.
🚗 Автоматический расчет: Вводите только километраж и литры заправки. Программа сама посчитает дневной расход и вычтет его из бака.
📊 Отчеты для бухгалтерии: Формируйте красивые PDF-отчеты с итогами по месяцам и общими периодами. Отправляйте их в бухгалтерию через WhatsApp или Telegram одной кнопкой! Есть выгрузка в Excel (CSV).
🔒 Полная конфиденциальность: Приложение работает полностью офлайн. Данные хранятся только в вашем телефоне. Никакой рекламы, слежки и лишних разрешений.
💾 Резервное копирование: Легко сохраняйте копию данных и восстанавливайте их при смене телефона.

Почему это удобно?
Записали данные за день за 10 секунд — и забыли. В конце месяца просто сформировали отчет и отправили руководителю. Приложение не требует регистрации и работает без интернета.
